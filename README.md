# 李傕列传自动化工具说明

作者：By 莲莲の锋刃 / By Anidlebrain

这是一个用于《三国杀》李傕列传的 Windows 自动化辅助工具。程序会通过截图识别游戏画面，并自动点击对应按钮。

## 一、使用前注意事项

### 1. 启动前请确认游戏窗口在前台

运行程序前，请先打开游戏，并进入到可以正常操作的界面。

如果游戏窗口被其他窗口遮挡，程序可能会识别不到模板图片，导致运行中断。

### 2. 当前支持组合

程序启动后会先进入“出战配置”入口页。当前按组合选择，不需要分别选择武将和将灵。

当前内置组合：

```text
神黄忠 + 曹纯
轲比能 + 神曹操
轲比能 + 曹纯
```

神曹操当前按“无将灵技能触发”处理；轲比能 + 曹纯会在寇旌确认后处理曹纯将灵技能。

### 3. 紧急停止方式

如果程序点击异常，或者运行失控，可以用以下方式停止：

- 点击 UI 中的“停止”按钮
- 将鼠标快速移动到屏幕左上角，触发 PyAutoGUI 的安全停止

### 4. 不同电脑上可能需要重新调整阈值

由于不同电脑的分辨率、缩放比例、游戏画质、窗口大小可能不同，识别效果可能会变化。

如果在一台电脑上正常，换到另一台电脑后识别不到，一般需要检查：

- 游戏窗口是否在前台
- 游戏窗口是否被遮挡
- 游戏缩放比例是否稳定
- 模板识别阈值是否需要调整

### 5. 不建议运行期间手动乱点

完整运行时，程序会自动识别并点击。运行期间不要手动点击游戏内按钮，否则可能打乱当前操作状态。

## 二、运行前参数设置

### 1. 文件夹结构

如果使用打包后的程序，建议保持如下结构：

```text
李傕列传/
├─ 李傕列传.exe
├─ templates/
├─ _internal/
└─ README.md
```

其中：

- `李傕列传.exe`：主程序
- `templates/`：识别模板图片
- `_internal/`：程序运行所需文件，不能删除
- `README.md`：说明文档

程序运行后可能会生成：

- `logs/`：文件日志
- `debug_screens/`：手动保存的调试截图
- `learned_templates/`：人工监督确认后的学习模板

### 2. templates 文件夹不能删除

`templates/` 文件夹用于存放所有识别图片。如果删除、移动或漏放图片，程序会找不到模板，日志里可能出现类似：

```text
模板不存在：xxx.png
```

## 三、阈值设置说明

点击 UI 中的“设置”可以打开参数设置窗口。

阈值越高，识别越严格。阈值越低，识别越宽松。常用范围：

```text
0.50 ~ 0.80
```

### 1. 各阈值含义

| 参数 | 中文含义 | 说明 |
|---|---|---|
| `THRESH_BUTTON` | 通用按钮阈值 | 用于开始挑战、取消、整理手牌等普通按钮 |
| `THRESH_SMALL` | 小图标/提示阈值 | 用于 `select_figure.png`、`select_figure_2.png` |
| `THRESH_CARD` | 手牌识别阈值 | 用于识别 `attack.png` 等通用手牌模板 |
| `THRESH_BOSS` | Boss 头像阈值 | 用于识别 `lijue.png` |
| `THRESH_HEAD` | 人体图阈值 | 用于识别 `head.png` |
| `THRESH_VICTORY` | 胜利界面阈值 | 用于识别 `victory.png` |
| `THRESH_SAVE` | 求桃阈值 | 用于识别 `save.png` |
| `THRESH_ACQUIRE` | 武将技能阈值 | 用于识别 `acquire.png` |
| `THRESH_REQUIRE` | 将灵技能询问阈值 | 用于识别 `require.png` |
| `THRESH_POPUP` | 弹窗技能阈值 | 用于识别 `increase_damage.png` 和 `xiaorui.png` |
| `THRESH_CONFIRM` | 确认按钮阈值 | 用于识别 `confirm.png` |
| `THRESH_SELECT_KEBINENG` | 轲比能选将阈值 | 用于识别 `select_kebineng.png` |
| `THRESH_KOUJING` | 寇旌技能阈值 | 用于识别 `koujing.png` |
| `THRESH_KEBINENG_CARD_MARKER` | 轲比能手牌标记阈值 | 用于识别 `kebineng_card_marker.png` |
| `THRESH_SELECT_ALL` | 全选按钮阈值 | 用于识别 `select_all.png`，默认比普通按钮更严格 |

### 2. 推荐初始阈值

如果没有特殊情况，可以先使用默认值：

```text
THRESH_BUTTON   = 0.65
THRESH_SMALL    = 0.65
THRESH_CARD     = 0.65
THRESH_BOSS     = 0.65
THRESH_HEAD     = 0.65
THRESH_VICTORY  = 0.65
THRESH_SAVE     = 0.65
THRESH_ACQUIRE  = 0.60
THRESH_REQUIRE  = 0.75
THRESH_POPUP    = 0.55
THRESH_CONFIRM  = 0.55
THRESH_SELECT_KEBINENG        = 0.65
THRESH_KOUJING                = 0.60
THRESH_KEBINENG_CARD_MARKER   = 0.70
THRESH_SELECT_ALL             = 0.75
```

### 3. 什么时候调高阈值？

如果出现以下情况，建议调高对应阈值：

- 没出现按钮，但程序误以为出现了
- 没有将灵技能，但误触发将灵技能处理
- 没有胜利，却误判胜利
- 没有对应卡牌，却误判有卡牌

例如 `require.png` 经常误识别，可以把 `THRESH_REQUIRE` 从 `0.75` 调高到 `0.78` 或 `0.80`。

### 4. 什么时候调低阈值？

如果出现以下情况，建议调低对应阈值：

- 明明有按钮，但程序识别不到
- 明明有卡牌，但程序识别不到
- 明明进入胜利界面，但检测不到胜利
- 明明出现武将技能，但检测不到技能提示

例如 `acquire.png` 识别不到，可以把 `THRESH_ACQUIRE` 从 `0.60` 调低到 `0.55`。

## 四、日志与调试

### 1. 查看日志

程序支持把运行日志写入 `logs/` 目录。调试阶段建议开启文件日志，出现问题时可以直接复制日志内容反馈。

日志里通常会记录：

- 当前选择的组合
- 当前运行阶段
- 模板识别置信度
- 点击坐标
- 关键等待和异常原因

### 2. 保存截图用于调试

点击 UI 中的“保存截图”，程序会保存当前屏幕到：

```text
debug_screens/
```

如果识别异常，可以把保存下来的截图和日志一起反馈。

### 3. 人工监督学习

如果开启人工监督，程序可能会弹出确认窗口，让你判断某个低置信度识别结果是否正确。

确认后的学习模板会保存到 `learned_templates/`。如果某个模板误学习，可以删除对应学习图片后重新运行。

## 五、设置缓存

程序会记住部分上次使用状态：

- 上次选择的组合
- 入口窗口位置
- 主控制台窗口位置
- 是否开启文件日志

如果需要重新选择组合，可以在主控制台点击“返回入口”。

## 六、运行中报错怎么处理

### 1. 程序一直等待

先查看日志里的当前阶段和正在等待的模板。通常需要确认游戏窗口是否在前台、画面是否被遮挡、阈值是否过高。

### 2. 程序误点或误判

可以先停止程序，调高相关阈值，再重新运行。

### 3. 程序识别不到按钮或卡牌

可以先保存截图，并尝试调低相关阈值。如果仍然识别不到，请反馈截图和日志。

### 4. 轲比能出牌卡住

轲比能会优先识别手牌上的“寇旌 杀”标记。如果识别数量明显不对，请保存截图，并连同日志一起反馈。
